# Demo GIFs for Projects

This folder contains demo GIFs for each project. Please place your demo GIFs in the appropriate subfolders:

## Folder Structure

- `diffusion-gen-studio/` - Demo GIFs for DiffusionArt Gen Studio project
  - `demo1.gif` - First demo GIF
  - `demo2.gif` - Second demo GIF

- `scichartvision/` - Demo GIFs for SciChartVision project
  - `demo1.gif` - First demo GIF
  - `demo2.gif` - Second demo GIF
  - `demo3.gif` - Third demo GIF
  - `demo4.gif` - Fourth demo GIF

- `ethereum-wallet/` - Demo GIFs for Ethereum Wallet project
- `banking-system/` - Demo GIFs for Banking System project
- `ted-talk-portal/` - Demo GIFs for TED Talk Portal project
- `cuda-ray-tracer/` - Demo GIFs for CUDA Ray Tracer project
- `romi-robot/` - Demo GIFs for Romi Robot project

## Usage

The website will automatically display these GIFs in the corresponding project sections. Make sure to name your GIFs exactly as specified above for them to appear correctly on the website.
